Dashboard Features

  • ✅ Live Data - WebSocket connection to backend for real-time quotes
  • ✅ Dynamic Tables - All rows generated from available contracts (no hardcoding)
  • ✅ Color Coding - Green for positive diffs, red for negative, gray for neutral
  • ✅ Three Separate Views
    • • Outrights - Direct contract-to-contract comparison
    • • 3MS - Three-month spreads (Jun-Sep, Sep-Dec, etc.)
    • • 3MF - Three-month butterflies (Jun/Sep/Dec, Sep/Dec/Mar, etc.)
  • ✅ Responsive Layout - Dark terminal theme with professional styling
  • ✅ Hover States - Subtle background highlight on row hover
  • ✅ Performance Optimized - useMemo hooks prevent unnecessary recalculations
  • ✅ Type Safe - Full TypeScript support for all calculations
